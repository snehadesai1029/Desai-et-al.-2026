# Multi-Omics Analysis Code

This repository contains analysis pipelines for:

- Proteomics analysis
- Gene expression analysis

## Repository Structure

### Proteomics/
Scripts for differential protein expression, WGCNA, enrichment analysis, and downstream analysis.

### Gene_expression/
Scripts for transcriptomic/gene expression analysis and downstream analysis.

## Data Availability

Figures and tables, including supplementary data, are provided with the publication.

Raw datasets will be made publicly available upon publication.
