# Gene Expression Analysis Code

This repository contains the analysis scripts used for the manuscript:

"Age- and amyloid-β-dependent initiation of neurofibrillary tau tangles: NLFTaum/h, an improved mouse model of Alzheimer's disease without mutations in MAPT" 

## Contents

- `scripts/` : Analysis scripts for preprocessing, differential expression analysis and enrichment analysis.

## Data Availability

Source data can be made upon request for review, and will be made publicly available upon publication. 

## Software

Analyses were performed in R.

## Reproducibility

Scripts are intended to be run sequentially.
